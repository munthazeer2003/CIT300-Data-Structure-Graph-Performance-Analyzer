# Data Structure & Graph Performance Analyzer

## Project Overview

The Data Structure & Graph Performance Analyzer is a menu-driven Java application developed to implement, demonstrate, and evaluate fundamental data structures and graph algorithms. The system provides an interactive command-line interface that allows users to perform various operations while analyzing algorithm performance through execution time and step-count metrics.

This project was developed as a collaborative software engineering assignment using professional GitHub workflows, including feature branching, pull requests, code reviews, and controlled merge strategies.

---

## Objectives

- Implement fundamental data structures from scratch.
- Demonstrate algorithm behavior through practical execution.
- Compare algorithm performance using real execution metrics.
- Apply Object-Oriented Programming (OOP) principles.
- Practice collaborative development using Git and GitHub.
- Produce maintainable and modular Java code.

# Algorithm Complexity Analysis

| Algorithm | Time Complexity |
|------------|----------------|
| Linear Search | O(n) |
| Binary Search | O(log n) |
| Breadth-First Search (BFS) | O(V + E) |
| Depth-First Search (DFS) | O(V + E) |

Where:

- V = Number of Vertices
- E = Number of Edges
